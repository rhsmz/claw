スタックポータル

ローカル Docker スタックの各 UI へジャンプします。ZeroClaw の公式ダッシュボードは :42617 で起動します（初回はペアリングが必要な場合があります）。

ZeroClaw ゲートウェイ

http://localhost:42617/

Web ダッシュボード・/health・ペアリング（ログに表示されるコード）。エージェントの状態確認はここが本体です。

LiteLLM

:4000

OpenAI 互換 API・Swagger UI。モデル一覧とヘルス確認。

Open WebUI

:8080

チャット UI（--profile ui 起動時）。

Langfuse

:3000

トレース・可観測性（--profile ui 起動時）。

rust-inference（llama-server）

:9080（既定）

OpenAI 互換 API はコンテナ内 :8080。ホスト公開ポートは .env の RUST_INFERENCE_HOST_PORT に合わせてください。

MCP Gateway

:8811 /sse

SSE は MCP クライアント用。ブラウザで開くと真っ白でも正常なことがあります。

このページは Nginx で静的配信されています。ポートは compose の stack-portal 設定（既定 8042）に合わせてください。
